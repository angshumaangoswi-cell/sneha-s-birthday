ROMANTIC BIRTHDAY WEBSITE — QUICK START

1. Extract this ZIP to a folder.
2. Install Visual Studio Code: https://code.visualstudio.com/
3. In VS Code, choose File > Open Folder and select the extracted folder.
4. Open index.html. For easy preview, install the Live Server extension, right-click index.html, and choose Open with Live Server. Or double-click index.html to open it in a browser.
5. Edit files and press Ctrl+S, then refresh the browser.

PERSONALISE:
- Open script.js and change recipientName and senderName near the top.
- Edit the letter paragraphs in index.html inside the element with id="letterText".
- To add photos, create an "images" folder beside index.html. Put images there, then replace each <div class="placeholder">...</div> in index.html with e.g.
  <img class="memory-image" src="images/memory1.jpg" alt="A favourite memory">
  Add this CSS at the bottom of style.css:
  .memory-image{display:block;width:100%;height:180px;object-fit:cover}
  @media(max-width:700px){.memory-image{height:200px}}
- Keep image names and capitalisation exact.

FREE HOSTING:
1. Sign in/create an account at https://github.com/
2. Create a new public repository named birthday-surprise.
3. Upload index.html, style.css, script.js and your images folder.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the published URL shown in Settings > Pages, then test it on your phone.

Privacy: a public website/repository may be visible to anyone with the link. Do not include private information. The sound effect is generated by the browser, not a commercial song recording.
